# TreeGUI

**TreeGUI** is a *Retained Mode* Graphical User Interface (GUI) library developed to simplify the creation of interfaces for games and applications in LÖVE (Love2D).

Focused on the developer experience, the library was designed to offer a clean and intuitive syntax, comprehensive documentation, and a native visual debugging interface to make screen adjustments easier.

Inspired by the Godot Engine's *Control Nodes* system, TreeGUI brings powerful and familiar concepts, such as **Anchors** and **Size Flags**. However, it is not a direct 1:1 port — the architecture was carefully rethought and adjusted to ensure the best possible integration and workflow within the LÖVE ecosystem.

## Features

- **Retained Mode Architecture:** Interface elements are stable and pre-configured objects, simplifying state management.
- **Smart Layout:** Flexible and responsive positioning using an adapted system of *Anchors* and *Size Flags*.
- **Visual Debugging:** Built-in debugging tools to inspect your GUI's hierarchy and margins in real time.
- **Elegant Syntax:** Readable code designed to keep your project's codebase clean.
- **Comprehensive Documentation:** Clear reference to help you start building interfaces immediately.
